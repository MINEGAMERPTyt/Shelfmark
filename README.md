# Shelfmark

**Catalog what you keep.**

A personal collection archive for physical video games.

[![License: MIT](https://img.shields.io/badge/License-MIT-d6ff4b?style=flat-square)](LICENSE)
[![Version](https://img.shields.io/badge/version-v1.5.0-d6ff4b?style=flat-square)](https://github.com/MINEGAMERPTyt/Shelfmark/releases)

[**Live Demo →**](https://shelfmark-app.netlify.app/)

## Features

- Physical game collection tracking
- Wishlist
- Custom Collections
- Collection statistics and value tracking
- Game details, condition and completeness
- Cover, manual, disc and cartridge photos
- Image cropper for cases and physical media
- Interactive 3D case and media viewer
- Portable backup and import
- Optional public Collection sharing
- Search, filtering, sorting and pagination
- Responsive desktop and mobile interface
- Private image storage with Supabase

## Physical media

Shelfmark supports a range of physical formats, including:

- CD / DVD / Blu-ray
- GameCube discs
- PSP UMDs
- NES, SNES and Nintendo 64 cartridges
- Game Boy, Game Boy Color and Game Boy Advance
- Nintendo DS and 3DS Game Cards
- Nintendo Switch Game Cards
- PS Vita Game Cards

Custom case dimensions and physical media formats are also supported.

## Technology

Shelfmark is built with:

- HTML
- CSS
- Vanilla JavaScript
- Supabase
- Netlify

No frontend framework or external 3D engine is required.

## Running locally

Clone the repository, configure your Supabase project in `js/supabase.js`, and serve the project through a local web server.

```bash
git clone https://github.com/MINEGAMERPTyt/Shelfmark.git
cd Shelfmark
```

Shelfmark uses Supabase Authentication, PostgreSQL, private Storage and Edge Functions.
